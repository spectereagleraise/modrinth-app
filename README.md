# Modrinth App

### The open-source Minecraft launcher from Modrinth

The Modrinth App is a clean, fast Minecraft launcher tightly integrated with the Modrinth mod platform. Browse, install, and update mods and modpacks from the world's fastest-growing open-source mod repository.

<br>

---

## Features

| | |
|:---|:---|
| **Modrinth Native** | Direct integration with Modrinth's 50,000+ mods and modpacks |
| **Fast Downloads** | CDN-backed downloads for quick installation of large modpacks |
| **Multi-Loader** | Supports Fabric, Quilt, Forge, NeoForge, and vanilla instances |
| **Open Source** | Fully open-source launcher with an active development community |
